# El Teremini — Android

Ön kameradaki elin görüntüde kapladığı alanı ölçerek seçilen gamın notalarını çalan çevrimdışı Android uygulaması.

## Açma ve çalıştırma

1. Klasörü Android Studio'da açın.
2. Gradle eşitlemesinin bitmesini bekleyin.
3. Android 8.0 veya üzeri bir telefona bağlanıp **Run** düğmesine basın.
4. Kamera iznini verin.
5. Telefonu dik tutun, yüzünüzü merkezde bırakın ve elinizi ekrandaki çerçeveye uzatın.

Varsayılan gam **La majör**dür. El uzaktayken kalın, kameraya yaklaştıkça ince notalar çalınır. Uygulama görüntü kaydetmez ve internet kullanmaz.

## İlk sürümün sınırı

El algılama, çalma bölgesindeki ten rengi oranıyla yapılır. Çok karanlık veya aşırı renkli ışıkta hassasiyet düşebilir. Sonraki sürümde cihaz üstü el-iskeleti modeli ve ikinci elle ses şiddeti kontrolü eklenebilir.
